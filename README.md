Student Performance Analytics System

About the Project

This project analyzes student marks and attendance using Python. It helps to understand student performance and identify students who need improvement.

Objectives

- Calculate total and average marks.
- Assign grades based on average marks.
- Identify pass and fail students.
- Find the class average and topper.
- Analyze subject-wise performance.
- Identify students with attendance below 75%.

Technologies Used

- Python
- Pandas
- NumPy
- Visual Studio Code

Input Dataset

The "students.csv" file contains student ID, name, department, marks in Python, DBMS and AIML, and attendance percentage.

Output

The program displays student results, grades, class statistics, topper details, subject averages and low-attendance students.

It also generates a file named "student_results.csv".

How to Run

1. Install Python.
2. Install the required libraries:
   "pip install pandas numpy"
3. Keep "main.py" and "students.csv" in the same folder.
4. Open the folder in VS Code.
5. Run:
   "python main.py"

Conclusion

This project uses basic data analysis to summarize student performance and make academic results easier to understand.
